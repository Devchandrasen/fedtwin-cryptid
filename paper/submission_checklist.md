# IEEE Transactions on Multimedia submission checklist

## Files

- [x] Main PDF, at most 10 pages for initial submission.
- [x] Supplement PDF, at most four pages.
- [x] Clean source-only Overleaf ZIP.
- [x] Cover-letter draft with explicit human confirmation gate.
- [x] Reproducibility README and reviewer artifact ZIP.
- [x] Preprint/prior-publication disclosure draft; author confirmation remains open.

## Content

- [x] Abstract is 150–250 words (221 by the checked source counter).
- [x] Title/abstract/contributions describe fixed-evidence calibration and audit, not a new retrieval/localization model.
- [x] SecureAgg simulation, quantized transport proxy, and real Paillier are accurately distinguished.
- [x] Separate VCSL visual and FMA audio tiers are not described as synchronized audio-video evidence.
- [x] No differential-privacy, ownership, legal-infringement, production-cryptography, or state-of-the-art localization claim is made.
- [x] Every numerical claim maps to `paper_results/v1/claims.csv` and the artifact manifest.
- [x] Figures contain finite values and remain legible at final size.
