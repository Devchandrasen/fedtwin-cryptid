# IEEE/SPS AI-use disclosure and author attestation

The IEEE requires disclosure of AI-generated text, figures, images, or code in
the acknowledgments. The IEEE Signal Processing Society additionally requires
authors to check all AI-assisted output thoroughly and does not permit an
entire manuscript section to be produced by a large language model.

The manuscript now discloses that OpenAI Codex (GPT-5) assisted with language
revision, code and test development, and table/figure preparation. Before
submission, every listed author must personally confirm that:

- the paper's scientific framing, experimental design, interpretation, and
  conclusions are the authors' work;
- no manuscript section remains entirely LLM-produced;
- every citation has been opened and checked for accurate attribution;
- every numerical claim has been reconciled to the released evidence;
- all AI-assisted code and verification scripts have been tested;
- every table, figure, caption, and limitation statement has been reviewed;
- the acknowledgment accurately describes the tools and level of assistance.

Policy sources checked on 15 July 2026:

- https://signalprocessingsociety.org/publications-resources/publication-guidelines/policy-on-using-large-language-models-llms
- https://open.ieee.org/author-guidelines-for-artificial-intelligence-ai-generated-text/

Submission remains blocked until the authors complete this attestation.
