# FedTwin-CryptID v1.0.0

This release is the reviewer-artifact candidate for the IEEE Transactions on Multimedia manuscript on federated fixed-evidence calibration and audit for multimedia copy review.

Highlights:

- portable `fedtwin` smoke, reproduce, regenerate, and verify commands;
- deterministic asset-disjoint positive-component pair construction;
- explicit synthetic, VCSL metadata, VCSL descriptor, and FMA audio adapters;
- strict run/artifact manifests and claim-to-result hashes;
- plain FedAvg/FedProx, SecureAgg arithmetic simulation, quantized transport proxy, and real Paillier compact-update aggregation;
- calibration/workload metrics, query-clustered bootstrap, paired permutation tests with Holm correction, dropout diagnostics, and multi-round poisoning stress;
- signed media-free receipt chains and tamper tests;
- locked dependencies, Python 3.10/3.12 CI, and at least 85% package coverage;
- source-only manuscript/supplement package and permitted derived evidence without restricted raw media.

Scientific boundaries:

This software is not a new multimedia retrieval or copy-localization model. It does not establish synchronized audio-video performance, differential privacy, production SecureAgg, encrypted media inference, ownership, infringement, or automated-enforcement readiness.
