# Reproducibility contract

FedTwin-CryptID separates executable code, restricted source data, and permitted derived evidence.

## Clean verification

```powershell
python -m pip install -e ".[test]"
python -m ruff check fedtwin tests run_benchmark.py run_smoke.py revision_blocker_experiments.py strengthen_for_tmm.py
python -m pytest --cov=fedtwin --cov-report=term-missing -q
python -m fedtwin.cli smoke --output-dir outputs\smoke
python -m fedtwin.cli reproduce --config configs\synthetic.yaml --output-dir outputs\synthetic-rerun
python -m fedtwin.cli verify-artifact --manifest paper_results\v1\manifest.json
python -m fedtwin.cli regenerate-paper --results-dir paper_results\v1 --output-dir outputs\paper-assets
```

Tests and `configs/synthetic.yaml` require no network and do not use data outside the repository. Full public-data experiments require explicitly staged inputs. `configs/paper.yaml` freezes seeds 31, 37, and 41, client count, pair limits, rounds, local epochs, attack/dropout settings, aggregation modes, and 2048-bit Paillier reporting.

## Run records

Every new run records the Git commit, canonical configuration hash, seed, dependency versions, input/output SHA-256 hashes, row and client counts, feature schema, elapsed time, Python/platform details, and hardware information. JSON is strict: non-finite values are rejected.

`paper_results/v1/claims.csv` maps manuscript claims to released rows. `paper_results/v1/manifest.json` hashes the artifact and is checked independently by `verify-artifact`.

## Evidence boundaries

- VCSL public-label evidence uses public metadata/topology and deterministic proxy features; it is not raw-descriptor copy localization.
- VCSL ISC is a separate visual-descriptor tier.
- FMA is a separate audio-transformation tier.
- The synthetic audio-video conflict tier is a stress test, not evidence from a natural synchronized piracy corpus.
- SecureAgg is a protocol-behavior simulation; the quantized transport mode is not encryption.
- Paillier protects compact update sums only. It does not provide encrypted media inference or production key management.
- No differential-privacy, ownership, infringement, or state-of-the-art localization claim is made.

## Restricted material

Raw media, downloaded descriptors, caches, and private labels are excluded. To rerun a restricted tier, obtain the upstream data under its own terms and pass its root explicitly. Derived result rows may be released only when their provenance and input/output checksums are verifiable.
