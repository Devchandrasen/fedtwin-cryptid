# FedTwin-CryptID frozen evidence, version 1

This directory contains derived numerical evidence, run configurations, output
manifests, checksums, and figure/table source data used by the TMM manuscript.
It contains no raw media, raw embeddings, downloaded descriptor archives, or
private labels.

## Evidence classes

- `new_runs/` contains the clean-commit confirmatory VCSL public-label, VCSL
  ISC, FMA audio, and feature-policy reruns. Pair-feature CSVs are excluded
  because they are regenerable and can encode dataset-derived identifiers.
- `archived_runs/` contains immutable historical outputs retained for audit
  traceability; they are not used to replace confirmatory manuscript rows.
- `tables/` contains the derived CSV sources used by the manuscript and
  supplement.
- `raw_summaries/` contains seed-level strengthening outputs where available.
- `claims.csv` maps each manuscript claim to its evidence file and validation
  status. A claim marked `verified` may be used in the submitted paper. A claim
  marked `exploratory-archived` or `replacement-required` must not be presented as confirmatory evidence.
- `manifest.json` is generated after the directory is frozen and records every
  file's SHA-256 digest and byte size.

## Verification and regeneration

From a clean repository checkout:

```powershell
python -m pip install -e ".[test]"
python -m fedtwin.cli verify-artifact --manifest paper_results/v1/manifest.json
python -m fedtwin.cli regenerate-paper --results-dir paper_results/v1 --output-dir outputs/paper_regenerated
```

The second command regenerates the multitier, feature-ablation, protected-update,
and cryptographic-accounting plots from finite CSV values. Remaining figures
are tied to source CSVs in `docs/REPRODUCIBILITY.md`.

## Dataset boundaries

VCSL metadata/descriptors and FMA media remain governed by their upstream terms.
Users must obtain them independently. See `data/README.md` for the expected local
layout and upstream project links. Synthetic data are generated by this codebase.

## Interpretation

The confirmatory evidence supports fixed-evidence calibration and audit experiments.
Legacy archived rows may use the historical labels `secureagg` and `heagg`;
these mean SecureAgg-style simulation and quantized transport proxy respectively,
not production SecureAgg or homomorphic encryption.
It does not establish state-of-the-art multimedia localization, synchronized
audio-video fusion, formal differential privacy, production SecureAgg, or legal
ownership/infringement conclusions.
